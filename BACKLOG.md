## 🧠 Меньше ложных пролётов стартовых ворот (итог 2026-06-23/24)

Проблема: реальных пролётов через **стартовые** ворота ~3–4 на видео, а детектор
(косинус по всему кадру) выдавал 11–22 кандидата — ловил «ворота видны», а не «пролетел
сквозь». Косинус по всему кадру эти случаи **не различает** (проверено: ни высота, ни обвал
после пика, ни prominence, ни ширина не разделяют true/false; предстартовый кадр даёт sim выше,
чем реальный пролёт). `min_lap_sec` тюнить нельзя — время круга заранее неизвестно и плавает.

- [x] **Умный фильтр ложных пролётов (внедрено).** Классификатор «настоящий пролёт / фейк»
  поверх эмбеддингов DINOv2, как фильтр кандидатов после `find_passes`. Обучен на
  верифицированных кадрах. LOSO CV: FP **9.6 → ~0.9 на видео (−90%)**, recall **0.93**, без
  тюнинга. См. [`core/pass_filter.py`](core/pass_filter.py), [`tools/`](tools/), README → «Умный фильтр».
  Кнопка ручного прогона (помечает только фейки) на вкладке верификации + тумблер авто-режима.

### Что пробовали и отбросили

- **YOLOE (visual-prompt, zero-shot)** — НЕ зашёл: не локализует блюр-фишай LED-ворота,
  выдаёт боксы во весь кадр; ни confidence, ни площадь не дают чистый сигнал. Бэкенд был
  добавлен и **откачен 2026-06-24**. К zero-shot YOLOE на этой задаче не возвращаться.
- **T-Rex2, DINO-X, Grounding DINO 1.5/1.6 Pro** — только облачное API, локальных весов нет.
- **UZH-FPV dataset** — VIO-бенчмарк, ворота НЕ размечены (для боксов — TII-RATM,
  [arXiv:2311.02667](https://arxiv.org/abs/2311.02667)).
