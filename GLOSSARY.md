# Глоссарий

## После клуба
Перенос записей полётов с флешки HDZero в архив после вечера в клубе: короткие записи удаляются, остальные переезжают в Выходную папку, картинки с флешки удаляются, затем запускается анализ кругов.
_Avoid_: импорт, синхронизация

## Флешка HDZero
Подключённый к компьютеру носитель, на котором есть Входная папка. Ровно одна такая флешка — условие запуска «После клуба».

## Входная папка
Папка `DCIM\100HDZRO` на Флешке HDZero, куда очки пишут записи.
_Avoid_: источник, папка с флешки

## Архив
Корневая папка, где лежат Выходные папки всех вечеров.

## Выходная папка
Папка внутри Архива с именем-датой вечера (`ГГГГ-ММ-ДД`), куда «После клуба» переносит записи. Одна на вечер; суффиксы к имени (например `_wazzup`) пользователь дописывает вручную.
_Avoid_: папка назначения, дата-папка
