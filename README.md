# FPV Lap Counter

Streamlit-приложение для анализа FPV-видеозаписей: автоматически находит пролёты через ворота, считает времена кругов и ищет лучшие серии подряд.

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![Streamlit](https://img.shields.io/badge/streamlit-1.56-red)

## Возможности

- 📁 Пакетный анализ папки с видео (`.ts`, `.mp4`, `.avi`, `.mov`, `.mkv`)
- 🧠 Детекция ворот через эмбеддинги (CLIP / DINOv2), выбор видеокарты
- 🖼 Референсные кадры ворот: загрузка из файла, буфера обмена, истории
- ⏳ Анализ идёт в фоне — интерфейсом можно пользоваться (проверять уже готовые видео), поток работает с приоритетом ниже среднего
- 📈 Интерактивный график сходства с кликом по пику → переход к кадру
- ✅ Верификация кандидатов: подтвердить / отметить как фейк / пакетные действия (все ✅, непроверенные ❌, сброс) + кнопка «непроверенные ❌ и следующий файл»
- 🤖 Умный фильтр ложных пролётов — обученный классификатор отсеивает кандидаты, не похожие на пролёт через стартовые ворота (см. ниже)
- 🏆 Таблица кругов, лучший одиночный круг и лучшие N подряд
- 📊 Сравнение нескольких видео + отметка «Оставить» и удаление остальных файлов
- 📦 Режим «После клуба»: перенос записей с флешки, удаление картинок и роликов короче 30 с, затем автоматический анализ
- 💾 Результаты сохраняются в JSON рядом с видео (`.fpv.json`); выбранные модель, видеокарта и настройки — между запусками

## Установка

```bash
pip install -r requirements.txt
```

> Для GPU нужен torch со сборкой под свою CUDA (см. pytorch.org). Конкретная видеокарта
> выбирается в боковой панели («Видеокарта»); по умолчанию — первая доступная, иначе CPU.

> Разрабатывается и проверено на **Streamlit 1.56**. Интерфейс опирается на свежий API
> (`st.iframe`, `st.segmented_control`, `st.fragment(run_every=…)`, `width='stretch'`),
> поэтому на заметно более старых версиях не запустится.

## Запуск

Windows: двойной клик по `FpvLapCounter.cmd` (открывает вкладку в Windows Terminal).

Либо вручную:

```bash
streamlit run app.py
```

## Использование

1. В боковой панели выбери папку с видео
2. Загрузи референсные кадры ворот (JPG/PNG или из буфера обмена)
3. Выбери модель и видеокарту, настрой параметры детекции (порог сходства, минимальная длина круга и т.д.)
4. Нажми **🚀 Обработать** — анализ пойдёт в фоне, интерфейс остаётся рабочим
5. Перейди на вкладку **✅ Верификация** и подтверди/отклони кандидатов. Кнопка внизу
   **«❌➡️ Непроверенные — фейк и следующий файл»** закрывает текущее видео и открывает следующее
6. Смотри результаты на вкладке **🏆 Круги** и **📊 Сравнение**

### Разбор после клуба

Кнопка **📦 После клуба** в основном окне — типовой сценарий за один проход:

1. Выбери папку-источник (флешка/карта с записями), папка назначения — та, что выбрана в сайдбаре
2. В окне подтверждения видно, сколько файлов переносится и сколько картинок удаляется
3. При переносе показывается прогресс (текущий файл + общий счётчик); ролики короче **30 с**
   удаляются как мусор, картинки с флешки — тоже
4. Сразу после переноса запускается фоновый анализ новых видео
5. Дальше — верификация, а на вкладке **📊 Сравнение** отметь галочкой «Оставить» удачные
   заезды и нажми **🗑 Удалить не отмеченные**

## Как работает детекция

1. Для каждого N-го кадра вычисляется косинусное сходство эмбеддинга кадра с эмбеддингами референсных изображений ворот
2. Временной ряд сходства сглаживается (Savitzky-Golay)
3. Пики выше порога = кандидаты на пролёт через ворота
4. **Умный фильтр** (если включён) отсеивает кандидаты, не похожие на пролёт через стартовые ворота
5. Пользователь верифицирует кандидатов, после чего пересчитываются круги (время круга — по видео-таймкоду)

## Умный фильтр ложных пролётов

Косинусное сходство по всему кадру не отличает «пролетел сквозь стартовые ворота» от «ворота
просто видны в кадре» — отсюда много ложных пиков. Умный фильтр решает это обученным
классификатором поверх тех же эмбеддингов DINOv2.

- **Где включается:** боковая панель → «🧠 Умный фильтр ложных» → тумблер «Отсеивать ложные
  пролёты» (применяется при анализе, состояние сохраняется между запусками). Можно не включать
  глобально, а пробовать вручную кнопкой **🧠 Умный фильтр** на вкладке верификации — она
  помечает фейки ❌, остальных не трогает.
- **Качество (leave-one-session-out CV):** ложные срабатывания ~9.6 → ~0.9 на видео (−90%)
  при recall ~0.93. Не требует подбора порога/времени круга.
- **Модель:** `storage/pass_classifier.joblib` (лёгкая логистическая регрессия). Работает
  независимо от выбранной модели детекции (для эмбеддингов использует DINOv2).

### Переобучение на своих данных

Чем больше верифицированных видео — тем точнее фильтр.

```bash
python tools/extract_gate_frames.py      # собрать кадры пролётов из всех .fpv.json в датасет
# (опционально вручную почистить мусорные кадры в датасете)
python tools/train_pass_classifier.py    # обучить + оценить (LOSO CV) и сохранить модель
```

Пути к датасету/видео заданы в начале скриптов (`tools/*.py`).
