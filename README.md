# FPV Lap Counter

Streamlit-приложение для анализа FPV-видеозаписей: автоматически находит пролёты через ворота, считает времена кругов и ищет лучшие серии подряд.

![Python](https://img.shields.io/badge/python-3.10%2B-blue)
![Streamlit](https://img.shields.io/badge/streamlit-1.40%2B-red)

## Возможности

- 📁 Пакетный анализ папки с видео (`.ts`, `.mp4`, `.avi`, `.mov`, `.mkv`)
- 🧠 Детекция ворот через эмбеддинги (CLIP / DINOv2)
- 🖼 Референсные кадры ворот: загрузка из файла, буфера обмена, истории
- 📈 Интерактивный график сходства с кликом по пику → переход к кадру
- ✅ Верификация кандидатов: подтвердить / отметить как фейк / пакетные действия (все ✅, все ❌, сброс)
- 🤖 Умный фильтр ложных пролётов — обученный классификатор отсеивает кандидаты, не похожие на пролёт через стартовые ворота (см. ниже)
- 🏆 Таблица кругов, лучший одиночный круг и лучшие N подряд
- 📊 Сравнение нескольких видео
- 💾 Результаты сохраняются в JSON рядом с видео (`.fpv.json`)

## Установка

```bash
pip install -r requirements.txt
```

> CUDA-видеокарта используется автоматически для EasyOCR и torch-моделей.

## Запуск

```bash
streamlit run app.py
```

## Использование

1. В боковой панели выбери папку с видео
2. Загрузи референсные кадры ворот (JPG/PNG или из буфера обмена)
3. Настрой параметры детекции (порог сходства, минимальная длина круга и т.д.)
4. Нажми **🚀 Обработать** — начнётся анализ выбранных видео
5. Перейди на вкладку **✅ Верификация** и подтверди/отклони кандидатов
6. Смотри результаты на вкладке **🏆 Круги** и **📊 Сравнение**

## Как работает детекция

1. Для каждого N-го кадра вычисляется косинусное сходство эмбеддинга кадра с эмбеддингами референсных изображений ворот
2. Временной ряд сходства сглаживается (Savitzky-Golay)
3. Пики выше порога = кандидаты на пролёт через ворота
4. **Умный фильтр** (если включён) отсеивает кандидаты, не похожие на пролёт через стартовые ворота
5. Для каждого кандидата OCR считывает время из OSD-таймера
6. Пользователь верифицирует кандидатов, после чего пересчитываются круги

## Умный фильтр ложных пролётов

Косинусное сходство по всему кадру не отличает «пролетел сквозь стартовые ворота» от «ворота
просто видны в кадре» — отсюда много ложных пиков. Умный фильтр решает это обученным
классификатором поверх тех же эмбеддингов DINOv2.

- **Где включается:** боковая панель → «🧠 Умный фильтр» (применяется при анализе, состояние
  сохраняется между запусками). Можно не включать глобально, а пробовать вручную кнопкой
  **🧠 Умный фильтр** на вкладке верификации — она помечает фейки ❌, остальных не трогает.
- **Качество (leave-one-session-out CV):** ложные срабатывания ~9.6 → ~0.9 на видео (−90%)
  при recall ~0.93. Не требует подбора порога/времени круга.
- **Модель:** `storage/pass_classifier.joblib` (лёгкая логистическая регрессия). Работает
  независимо от выбранной модели детекции (для эмбеддингов использует DINOv2).

### Переобучение на своих данных

Чем больше верифицированных видео — тем точнее фильтр.

```bash
python tools/extract_gate_frames.py      # собрать кадры пролётов из всех .fpv.json в датасет
# (опционально вручную почистить мусорные кадры в датасете)
python tools/train_pass_classifier.py    # обучить + оценить (LOSO CV) и сохранить модель
```

Пути к датасету/видео заданы в начале скриптов (`tools/*.py`).
